# Запуск через Docker Compose

Перед первым запуском должны существовать файлы `.env` и `tennis.db`. Текущая база данных будет один раз скопирована в постоянный Docker-volume.

Порт задаётся в `.env`, например `PORT=5000`. Внешний адрес задаётся одной переменной, например `EXTERNAL_URL=https://sport.silaeder.ru`. Из неё автоматически формируются QR-ссылки и адреса возврата OIDC.

Обязательно задайте случайный `ADMIN_PASSWORD` длиной не менее 12 символов. `QR_BASE_URL` должен содержать адрес, который доступен с телефонов учеников. По умолчанию публикация Docker ограничена `BIND_ADDRESS=127.0.0.1`; открывайте `0.0.0.0` только в доверенной сети или за HTTPS reverse proxy.

Если HTTPS завершается на reverse proxy, установите `EXTERNAL_URL=https://ваш-домен` и включите `TRUST_PROXY_HEADERS=true`. Не включайте эту настройку при прямом доступе к Waitress.

Если обычный локальный сервер уже работает на порту 5000, сначала остановите его. Затем выполните:

```powershell
docker compose up -d --build
```

Сайт будет доступен по адресу <http://localhost:5000> и по IP компьютера в школьной сети на порту 5000.

Проверить состояние:

```powershell
docker compose ps
docker compose logs -f tennis
```

Остановить сайт без удаления данных:

```powershell
docker compose down
```

После изменения исходного кода пересоберите образ:

```powershell
docker compose up -d --build
```

Актуальные данные хранятся в volume `tennis-data-v2`. Старый `tennis-data` подключён только для чтения и оставлен для безопасного отката. Команда `docker compose down -v` удалит оба volume вместе с Docker-копиями базы данных.
